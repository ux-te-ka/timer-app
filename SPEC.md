# Timer — SPEC

## Screens/Компонент
Один екран: компонент `Timer` (логіка + розмітка) змонтований у `App`. Жодних інших сторінок/роутів.

## States
- **idle** — `00:00`, лічильник не йде. Доступна лише кнопка **Start**.
- **running** — лічильник тікає (+1с щосекунди). Доступні **Pause** і **Reset**.
- **paused** — лічильник зупинений на поточному значенні. Доступні **Start** (продовжити з цього значення) і **Reset**.

## Behavior
- **Start** (з idle або paused) → `running`; лічильник рахує далі від поточного значення (не з нуля, якщо це продовження після paused).
- **Pause** (з running) → `paused`; значення зберігається.
- **Reset** (з running або paused) → `idle`, `00:00`.
- Формат відображення: `mm:ss` з провідними нулями (`00:07`, `01:05`).
- У кожному стані видимі лише релевантні кнопки (не задизейблені — приховані), щоб не було потреби в disabled-стилях.

## Edge cases
- **Reset під час running**: одразу зупиняє й скидає в `00:00` — без проміжного paused.
- **Подвійний Start**: неможливий за конструкцією — в стані `running` кнопки Start немає взагалі (лише Pause/Reset).
- Розмонтування компонента під час running: інтервал (`setInterval`) обов'язково чиститься в cleanup, щоб не текла пам'ять і не було помилок у консолі.
- Дуже довгий час (>99:59): хвилини необмежені, просто показуємо фактичну кількість (напр. `125:07`).
