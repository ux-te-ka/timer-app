# Timer — SPEC

## Screens/Компонент
Один екран: компонент `Timer` (логіка + розмітка) змонтований у `App`. Жодних інших сторінок/роутів.

## States
- **idle** — `00:00`, лічильник не йде. Доступна лише кнопка **Start**.
- **running** — лічильник тікає (+1с щосекунди). Доступні **Pause** і **Reset**.
- **paused** — лічильник зупинений на поточному значенні. Доступні **Start** (продовжити з цього значення) і **Reset**.

## Behavior
- **Start** (з idle або paused) → `running`; лічильник рахує далі від поточного значення (не з нуля, якщо це продовження після paused).
- **Pause** (з running) → `paused`; значення зберігається.
- **Reset** (з running або paused) → `idle`, `00:00`.
- Формат відображення: `mm:ss` з провідними нулями (`00:07`, `01:05`).
- У кожному стані видимі лише релевантні кнопки (не задизейблені — приховані), щоб не було потреби в disabled-стилях.

## Edge cases
- **Reset під час running**: одразу зупиняє й скидає в `00:00` — без проміжного paused.
- **Подвійний Start**: неможливий за конструкцією — в стані `running` кнопки Start немає взагалі (лише Pause/Reset).
- Розмонтування компонента під час running: інтервал (`setInterval`) обов'язково чиститься в cleanup, щоб не текла пам'ять і не було помилок у консолі.
- Дуже довгий час (>99:59): хвилини необмежені, просто показуємо фактичну кількість (напр. `125:07`).

## Visual — iOS 26 (Liquid Glass)
Поведінка вище не змінюється — лише вигляд.

- **Стиль** (за референсами користувача): high-end premium glass на чорному — прозоре скло, крізь яке світить кольорове світло, білий текст.
- **Фон**: майже чорний. Позаду таймера — 3D-орбіта світла (дуга фіолетовий → світло-бузковий → помаранчевий, нахилена в перспективі), що повільно обертається й хитається, проходячи під склом; м'яке фіолетове світіння позаду панелі. Фон декоративний (`aria-hidden`). При `prefers-reduced-motion` — статичний.
- **Скляна панель**: без суцільної заливки — над чорним скло лишається прозорим, а не сірим; читається за тонкою світлою гранню (яскравіша зверху-зліва), внутрішнім відблиском по краях і діагональним бліком. Крізь скло фон розмитий і підсилений (`blur + saturate + brightness`). Ребриста (fluted) текстура — широкі м'які ребра (крок 24px, низька інтенсивність), чіткі в центрі, згасають до країв; просвічують і крізь кнопки. Легке зерно. Радіус ~44px, глибока тінь.
- **Цифри**: великі, тонкі (weight ~200, як у годиннику iOS), білі, `tabular-nums`, системний шрифт (SF Pro на Apple-пристроях).
- **Кнопки**: квадратні з заокругленням (~92px, радіус ~28px), темне прозоре скло, тонка грань. Колір функції — м'яке світіння знизу всередині кнопки, ореол довкола й відтінок нижньої грані: Start — фіолетовий (у тон орбіти; контраст підпису перевірено), Pause — жовтий (amber), Reset — рожево-кораловий. Підписи білі, 18px semibold. Натискання: легке стискання (scale ~0.96).
- **Візуальна різниця станів**: у paused цифри трохи приглушені (≈70% непрозорості — 60% не проходило контраст у найгіршому кадрі анімації) — лише вигляд, без нового функціоналу.
- **Fallback**: якщо браузер не підтримує `backdrop-filter` — щільний темний фон замість розмиття, текст лишається читабельним.
- **a11y**: видимий `:focus-visible` на кнопках; контраст підписів кнопок ≥ 4.5:1, цифр (великий текст) ≥ 3:1 — у найгіршій точці анімації фону, не лише на одному кадрі.
- **Адаптив**: на телефоні панель займає ширину екрана з відступами, кнопки не менші за 64px.

## Dribbble-шот
- Формат: **1600×1200 (4:3)** PNG, без браузерної рамки, композиція по центру.
- 3 кадри: **idle**, **running**, **paused**, зі "фотогенічним" часом (напр. `12:34`), а не `00:03`.
- Щоб зняти running/paused з конкретним часом, додається **dev-only** параметр URL (`?state=paused&t=754`) — працює лише в `npm run dev`, у продакшн-білд не потрапляє.
- Готові файли кладуться в `shots/` у репозиторії.
